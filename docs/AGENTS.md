# Documentation Guidelines

- Keep work-item definitions, execution order, dependencies, status, decisions, and verification evidence in `docs/work-items/`.
- Do not update `docs/requirements/overview.md` for routine work-item creation, edits, reordering, or status changes. Do not add requirement IDs or work-item summaries there solely to mirror a work item.
- Update the requirements overview only when an actual product-scope or requirement change needs to be recorded, or when the user explicitly requests it.
